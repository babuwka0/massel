## Лабораторная 1. Экспертная система в CLIPS

Тема: экспертная система выбора ноутбука.

### Что делает программа?

Программа задает пользователю вопросы про требования к ноутбуку. Ответы `yes` превращаются в факты CLIPS, а потом правила выбирают подходящие рекомендации.

Коротко:

```text
вопросы -> факты -> правила -> рекомендации
```

### Почему это экспертная система?

Потому что есть база знаний в виде правил. Правила работают как советы эксперта:

```text
если нужны игры и высокий бюджет, то советуем игровой ноутбук
```

### Что такое факт?

Факт - это утверждение, которое хранится в рабочей памяти CLIPS.

Примеры:

```clips
(gaming)
(programming)
(high-budget)
```

### Что такое правило?

Правило описывает условие и действие.

```clips
(defrule advise-gaming-laptop
   (answers-collected)
   (gaming)
   (high-budget)
   =>
   (printout t "..." crlf))
```

Если факты `(answers-collected)`, `(gaming)` и `(high-budget)` есть в памяти, правило срабатывает.

### Зачем нужен `initial-fact`?

`initial-fact` запускает начальное правило после команды `(reset)`. В нашей программе через него стартует опрос пользователя.

### Что делает `deffacts`?

`deffacts` задает начальные факты.

```clips
(deffacts start-facts
   (initial-fact))
```

После `(reset)` этот факт появляется в рабочей памяти.

### Что делает `deffunction ask`?

Функция `ask` выводит вопрос, читает ответ пользователя и возвращает его.

Она также переводит:

```text
y -> yes
n -> no
```

### Что делают основные команды CLIPS?

- `(load "file.clp")` - загрузить программу.
- `(reset)` - очистить рабочую память и добавить стартовые факты.
- `(run)` - запустить правила.
- `(facts)` - показать текущие факты.
- `(rules)` - показать список правил.
- `(clear)` - полностью очистить среду CLIPS.

### Что делают основные конструкции?

- `defrule` - создает правило.
- `deffacts` - задает начальные факты.
- `deffunction` - создает функцию.
- `assert` - добавляет факт.
- `bind` - записывает значение в переменную.
- `read` - читает ввод пользователя.
- `printout` - выводит текст.
- `eq` - проверяет равенство.
- `not` - проверяет отсутствие факта.
- `salience` - задает приоритет правила.

### Зачем нужен `(answers-collected)`?

Этот факт показывает, что опрос завершен. Рекомендации зависят от него, чтобы не сработать раньше времени.

### Почему рекомендаций может быть несколько?

Потому что пользователь может подходить под несколько правил сразу. Например, ему может быть нужен ноутбук для программирования и частых поездок.

### Что такое `salience -100`?

Это низкий приоритет. Финальное правило с таким приоритетом срабатывает после остальных, чтобы сообщение о завершении было в конце.

### Контрольные вопросы по теории

**Данные** - отдельные факты без объяснения.

**Информация** - данные, которые получили смысл.

**Знания** - правила и связи, по которым можно делать выводы.

**База знаний** - место, где хранятся знания экспертной системы.

**Рабочая память** - место, где во время работы хранятся текущие факты.

**Механизм вывода** - часть системы, которая проверяет факты и запускает подходящие правила.

**Продукционная модель** - представление знаний через правила вида «если условие, то действие».

**Фреймовая модель** - описание объектов через набор свойств, то есть слотов.

**Экспертная оболочка** - готовая среда для создания экспертных систем. CLIPS подходит под это описание.

## Лабораторная 2. Генетический алгоритм

Тема: генетический алгоритм для функции `y = ln(4x)`, вариант 22.

### Что делает программа?

Программа пытается приблизить график функции:

```text
y = ln(4x)
```

Она создает случайные варианты графика, сравнивает их с настоящей функцией, оставляет лучшие и постепенно улучшает результат.

### Почему начинается с `x = 0.1`, а не с `x = 0`?

Потому что `ln(4x)` при `x = 0` не существует.

```text
ln(0) не определен
```

Поэтому берутся точки от `0.1` до `10.0` с шагом `0.1`.

### Что такое особь?

Особь - это список из 100 чисел. Эти числа являются предполагаемыми значениями функции в 100 точках.

Пример по смыслу:

```python
[0.1, 0.3, 0.5, ...]
```

### Что такое популяция?

Популяция - это набор особей.

В программе:

```python
POPULATION_SIZE = 20
```

То есть в каждом поколении остается 20 лучших особей.

### Почему признаков 100?

Потому что участок от `0.1` до `10.0` берется с шагом `0.1`. Получается 100 точек.

```python
x_values = [round((i + 1) * 0.1, 1) for i in range(GENES_COUNT)]
```

### Что такое целевая функция?

Это настоящие значения функции `ln(4x)`, с которыми сравниваются особи.

```python
target_function = [math.log(4 * x) for x in x_values]
```

### Что делает `create_individual()`?

Создает одну случайную особь. Значения берутся в диапазоне около минимального и максимального значения целевой функции.

### Что такое функция приспособленности?

В этой программе приспособленность считается через эвклидово расстояние.

Чем меньше расстояние, тем лучше особь.

### Что такое эвклидово расстояние?

Это мера отличия одной кривой от другой.

Программа считает разницу между каждым значением особи и настоящей функции, возводит разницы в квадрат, складывает и берет корень.

```python
distance += (individual[i] - target_function[i]) ** 2
return math.sqrt(distance)
```

### Что делает `crossover`?

`crossover` - это скрещивание двух родителей.

Для каждого признака программа случайно выбирает, от какого родителя взять значение.

```python
if random.random() < 0.5:
    child.append(parent1[i])
else:
    child.append(parent2[i])
```

### Что делает `mutate`?

Мутация случайно немного меняет некоторые признаки особи.

```python
if random.random() < MUTATION_RATE:
    individual[i] += random.uniform(-mutation_power, mutation_power)
```

`MUTATION_RATE = 0.1` означает вероятность мутации 10 процентов для каждого признака.

### Что такое `mutation_power`?

Это сила изменения признака при мутации.

Если `mutation_power = 0.1`, значение может измениться в пределах от `-0.1` до `+0.1`.

### Что делает `select_best`?

Функция считает расстояние для каждой особи, сортирует популяцию и оставляет 20 лучших.

### Как работает цикл алгоритма?

```text
создать популяцию
посчитать расстояние
выбрать лучших
создать потомков
сделать мутации
удвоить популяцию
оставить 20 лучших
повторять до расстояния <= 0.5
```

### Почему итоговое расстояние может быть меньше 0.5, а не ровно 0.5?

Потому что алгоритм улучшает результат скачками.

Например:

```text
0.54 -> 0.49
```

Как только расстояние стало меньше или равно `0.5`, программа останавливается.

### Зачем `random.seed(22)`?

Он фиксирует случайность. При повторном запуске результат получается примерно одинаковым.

Число `22` выбрано из-за номера варианта.

### Что показывает график?

На графике есть настоящая функция `ln(4x)` и лучшая найденная особь. Если линии близко, алгоритм сработал хорошо.

### Что могут спросить по теории ГА?

**Генетический алгоритм** - метод поиска решения через имитацию эволюции.

**Особь** - один вариант решения.

**Ген** - один элемент особи.

**Популяция** - набор особей.

**Скрещивание** - создание потомка из двух родителей.

**Мутация** - случайное изменение признаков.

**Селекция** - отбор лучших особей.

**Функция приспособленности** - оценка качества решения.

## Лабораторная 3. EDA продаж видеоигр

Тема: разведочный анализ данных по датасету продаж видеоигр.

### Что делает программа?

Программа загружает `vgsales.csv`, изучает структуру данных, строит графики, ищет пропуски, выбросы, связи между признаками и формулирует гипотезы.

### Что такое EDA?

EDA - это разведочный анализ данных. Он нужен, чтобы понять, что находится в датасете, какие есть проблемы и какие закономерности можно использовать дальше.

### Какие библиотеки используются?

- `pandas` - работа с таблицами.
- `numpy` - числовые операции.
- `matplotlib` - построение графиков.
- `pathlib` - удобная работа с путями.

`seaborn` не используется, потому что он не установился. Все графики сделаны через `matplotlib` и `pandas`.

### Что за датасет?

Датасет содержит продажи видеоигр:

- `Name` - название игры;
- `Platform` - платформа;
- `Year` - год выпуска;
- `Genre` - жанр;
- `Publisher` - издатель;
- `NA_Sales` - продажи в Северной Америке;
- `EU_Sales` - продажи в Европе;
- `JP_Sales` - продажи в Японии;
- `Other_Sales` - продажи в остальных регионах;
- `Global_Sales` - глобальные продажи.

Продажи указаны в миллионах копий.

### Что делает `pd.read_csv`?

Читает CSV-файл и превращает его в таблицу `DataFrame`.

```python
df = pd.read_csv(DATA_PATH)
```

### Зачем переименовывается `Global Sales`?

В исходном датасете название колонки содержит пробел. Программа меняет его на `Global_Sales`, чтобы удобнее обращаться к столбцу.

```python
df = df.rename(columns={"Global Sales": "Global_Sales"})
```

### Что выводится в начале?

Программа выводит:

- размер датасета;
- типы данных;
- первые 5 строк;
- последние 5 строк;
- пропущенные значения;
- основные статистики;
- уникальные значения категориальных признаков.

### Как проверяются пропуски?

```python
df.isnull().sum()
```

В датасете был один пропуск в `Global_Sales`.

### Как он заполняется?

Пропуск в глобальных продажах заполняется суммой региональных продаж.

```python
df["Global_Sales"] = df["Global_Sales"].fillna(
    df[["NA_Sales", "EU_Sales", "JP_Sales", "Other_Sales"]].sum(axis=1)
)
```

### Какие графики строятся?

1. Количество выпущенных игр по годам.
2. Топ-10 платформ по глобальным продажам.
3. Глобальные продажи по жанрам.
4. Распределение глобальных продаж.
5. Boxplot глобальных продаж.
6. Региональные продажи по жанрам.
7. Корреляционная матрица.
8. Динамика региональных продаж по годам.
9. Топ-10 издателей по глобальным продажам.

Она сохраняет графики в папку `figures`.

```python
plt.savefig(...)

```

Так окна не открываются, а картинки можно вставить в отчет.

Чтобы консоль не закрывалась сразу. Это удобно, если запускать программу двойным кликом или из IDE.

### Что показывает boxplot?

Он показывает выбросы в глобальных продажах.

В датасете большинство игр продается небольшими тиражами, но есть хиты вроде `Wii Sports`. Поэтому boxplot сжат слева, а справа много точек-выбросов.

Эти выбросы не ошибка. Это реальные игры с очень большими продажами.

### Что такое IQR?

IQR - межквартильный размах.

```text
IQR = Q3 - Q1
```

В программе выбросами считаются игры, у которых `Global_Sales` больше:

```text
Q3 + 1.5 * IQR
```

### Что показывает корреляционная матрица?

Она показывает связь между числовыми признаками.

Значение близко к `1` - сильная прямая связь.

Значение около `0` - связи почти нет.

В нашем анализе `Global_Sales` сильно связаны с региональными продажами, особенно с `NA_Sales` и `EU_Sales`.

### Почему `Year` почти не связан с продажами?

Потому что сам год выпуска не гарантирует успех игры. На продажи сильнее влияют платформа, жанр, издатель и популярность конкретной игры.

### Какие гипотезы сформулированы?

1. Жанр игры влияет на глобальные продажи.
2. Платформа влияет на коммерческий успех игры.
3. Региональные предпочтения отличаются: продажи в Японии распределены по жанрам иначе, чем в Северной Америке и Европе.

- Самый продаваемый жанр в анализе - `Action`.
- Лидирующая платформа по продажам - `PS2`.
- Лидирующий издатель - `Nintendo`.
- В данных есть выбросы, но их лучше не удалять.

- Числовые признаки при необходимости нужно масштабировать.
